# Gulgulii

Decoration Company

Website for GulGulii (گلگلی): flowerwork, handcrafts, gift packaging, wedding stage design, bride and groom bedroom decoration and wedding car flowers in Kabul.

- Live site: https://alphadudesnft-coder.github.io/Gulgulii/
- Plain static site (no build step): `index.html`, images in `img/`.
- Languages: Dari (default, right to left) and English, switched with the button in the header. All text lives in the `T` object and the `SERVICES` list near the bottom of `index.html`.
- Prices are in the `SERVICES` list in `index.html`.
